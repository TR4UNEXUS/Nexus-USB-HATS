# Nexus USB HATS — 24 October 2026

A ready-made toolbox for an already modified Nintendo Switch, bringing Nexus USB tools, homebrew apps and supporting files together in one pack.

## Download

- **Nexus-USB-HATS-2026.10.24.zip** — the Switch software pack.
- **Nexus-USB-Formatter-1.6.1.exe** — the separate Windows USB preparation utility (the supplied application identifies itself as a test build).
- **SHA256SUMS.txt** — checksums for verifying the downloads.

Select the named HATS ZIP under **Assets**. GitHub's automatic “Source code” ZIP and TAR.GZ downloads contain repository documentation.

## Included Nexus components

USB Loader 0.7.29, Nexus Manager 0.1.1, Goldleaf NEXUS USB 1.2.1-G2 and DBI 864, alongside the supplied Atmosphère/Hekate files and homebrew utilities.

## Public package preparation

Console backups, encryption key files, personal saves, account and connection settings, paired-device data, local USB preferences, logs, caches and old local backups have been excluded. Personal file-browser history was cleared. The USB content enabled setting was retained. Original private files were not changed.

The ZIP passed an archive integrity check, and SHA-256 checksums were generated. Programs were not run or rebuilt, and console compatibility was not tested during packaging. Back up your setup before making changes. The formatter's **Erase / Format** option deletes files on the selected USB drive.
