# Nexus USB HATS

**A ready-made toolbox for a modified Nintendo Switch, with Nexus USB tools, homebrew apps and a Windows USB formatter in one place.**

Think of it as a collection of useful apps and settings already gathered into one pack. It brings together tools for starting your custom Switch setup, managing files and USB storage, backing up saves, and viewing useful information on screen. “Homebrew” simply means apps made by independent developers for the console.

An already modified Switch that can run homebrew is required. The pack's folders are arranged for a Switch microSD card; the separate formatter runs on a Windows PC to prepare a USB drive.

## What's included

- **Nexus USB Loader 0.7.29** and its supplied home-menu package.
- **Nexus Manager 0.1.1**.
- **Goldleaf NEXUS USB 1.2.1-G2** and **DBI 864**.
- Atmosphère and Hekate files for the custom setup.
- A collection of homebrew utilities, save-management apps, controller tools and on-screen overlays.
- The separate **Nexus USB Formatter 1.6.1** for Windows.

The versions above were read from the supplied files. This is a packaged download release, not a hardware compatibility certification.

## Before using it

Back up your existing microSD card and any USB files you want to keep. Check that the included software suits your console and firmware before replacing your setup. The Windows formatter's **Erase / Format** option deletes the selected drive's files, so check the drive name and capacity carefully.

Download and extract the HATS ZIP on your PC to inspect its contents. Keep your own console-specific files and settings. The formatter is a separate Windows download and does not need to be placed on the Switch microSD card.

## About this public copy

Console backups, encryption key files, personal saves, account and remote-connection settings, paired-device data, local device preferences, logs and temporary caches were excluded before publication. Personal file-browser history was cleared. The USB content enabled setting was retained. The original private archive was left unchanged.

The remaining programs were copied from the supplied bundle; they were not rebuilt or run during release preparation. Archive integrity and download checksums were checked. The bundle has not been tested on a console as part of this publication.
