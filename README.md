# Nexus USB HATS

**Install and play Nintendo Switch games from external HDDs, SSDs and USB flash drives.**

Nexus USB HATS brings external USB game storage to a compatible modified Nintendo Switch. It combines the Nexus USB tools, custom firmware files and supporting homebrew apps in one pack, allowing you to install games to an external drive and play them directly from that drive.

Keep a larger game library on external storage while your microSD card provides the console's custom firmware and homebrew setup.

**[Download the latest release](https://github.com/TR4UNEXUS/Nexus-USB-HATS/releases/latest)**

## What the pack does

- **Install games to external storage** — use an external HDD, SSD or USB flash drive for your game library.
- **Play directly from the connected drive** — launch games stored on external USB storage.
- **Manage your USB setup** — access the included Nexus Loader, Nexus Manager and supporting file-management tools.
- **Prepare drives on Windows** — use the separate Nexus USB Formatter to inspect and prepare a USB drive.
- **Keep useful homebrew tools together** — the pack also includes save-management utilities, controller tools and on-screen overlays.

## External storage options

| Drive type | Typical use |
| --- | --- |
| **External HDD** | Keeping a large game library on a hard drive. |
| **External SSD** | Using a compact solid-state drive for your library. |
| **USB flash drive** | Carrying a smaller selection of games on a portable USB stick. |

Your drive, connection and console setup must be compatible with the included software. Keep the external drive connected while installing or playing games stored on it.

## Requirements

- A compatible modified Nintendo Switch configured to run custom firmware and homebrew.
- A microSD card for the Switch setup and the HATS pack.
- An external HDD, SSD or USB flash drive, with a suitable USB connection and adequate power.
- A Windows PC if you want to use Nexus USB Formatter.

Back up your existing microSD card and USB files before changing your setup. Check compatibility with your console and firmware before replacing existing files.
